# Application Fees — University of Mauritius

## Mauritian Applicants
- An application fee is payable when submitting an online application.
- The fee is **non-refundable**.
- Exact amount should be confirmed on the current application portal.

## International Applicants
- Non-refundable Application Fee: **USD 50** (as stated in official regulations).
- Proof of payment must be sent together with the application number and required documents to the designated email (intstudpaylt@uom.ac.mu or as indicated on the portal).

## Payment Notes
- Always include the Application Number when making payment.
- Incomplete applications (including missing proof of payment) will not be considered.

**Sources:**
- University Regulations Chapter 14
- https://www.uom.ac.mu/index.php/application-process
